## Mi primera web estática

En esta práctica he aprendido a utilizar Jekyll para generar una página web estática a partir de archivos Markdown.

También he configurado GitHub Actions para automatizar la generación y publicación de la web en GitHub Pages.

### Lo que he aprendido

- Crear publicaciones utilizando Markdown.
- Organizar el contenido mediante archivos y carpetas.
- Generar la web con Jekyll.
- Publicar la web automáticamente mediante GitHub Actions.
